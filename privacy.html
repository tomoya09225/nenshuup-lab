プライバシーポリシー

制定日：2026年10月26日

年収UP研究所（以下「運営者」）は、YouTube チャンネル「年収UP研究所」への動画投稿に使用する社内ツール（以下「本ツール」）における情報の取り扱いを、以下のとおり定めます。

1. 本ツールの目的

本ツールは、運営者が作成した動画を、YouTube Data API を通じて運営者自身の YouTube チャンネルにアップロードし、公開設定と再生数などの統計を管理するためだけに使用します。第三者のアカウントには使用しません。

2. 取得する情報

  • 運営者自身の Google アカウントで許可した OAuth 認証情報（アクセストークン・リフレッシュトークン）
  • 運営者のチャンネルの動画情報（タイトル・説明・公開状態・再生数などの統計）

本ツールは、視聴者や第三者の個人情報を取得・保存しません。

3. 情報の利用と保存

取得した情報は、動画のアップロードと投稿状況の管理にのみ使用し、運営者の PC 内にのみ保存します。第三者への提供・販売は行いません。

4. YouTube API サービスの利用

本ツールは YouTube API サービスを使用しています。YouTube の利用規約（https://www.youtube.com/t/terms）および Google のプライバシーポリシー（https://policies.google.com/privacy）が適用されます。

5. 許可の取り消し

本ツールへのアクセス許可は、Google アカウントのセキュリティ設定（https://myaccount.google.com/permissions）からいつでも取り消せます。取り消すと、保存された認証情報は使用できなくなり、運営者は PC 内の認証情報を削除します。

6. お問い合わせ

メール：tokyodatespot1997@gmail.com

Privacy Policy (English)

Effective: October 26, 2026

"Nenshu UP Lab" (the "Operator") uses an internal tool (the "Tool") only to upload the Operator's own videos to the Operator's own YouTube channel through the YouTube Data API, and to manage their privacy status and statistics.

  • Data accessed: OAuth tokens granted by the Operator's own Google account, and metadata/statistics of the Operator's own channel videos. The Tool does not collect personal data of viewers or any third party.
  • Use and storage: Data is used only for uploading and managing the Operator's videos and is stored only on the Operator's computer. It is never shared with or sold to third parties.
  • YouTube API Services: The Tool uses YouTube API Services. By using it, the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy) apply.
  • Revoking access: Access can be revoked at any time via Google security settings (https://myaccount.google.com/permissions). Stored tokens are then deleted.
  • Contact: tokyodatespot1997@gmail.com
