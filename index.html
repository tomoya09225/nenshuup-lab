動画の作り方について

  • 動画内の数値は、国税庁「民間給与実態統計調査」や厚生労働省「就労条件総合調査」などの公的データ、および法令にもとづいています。出典は各動画の説明欄に記載しています。
  • 動画は、運営者が作成した台本をもとに、社内用のツールで自動編集し、YouTube Data API を使って運営者自身のチャンネルにのみ投稿しています。
  • このツールは運営者のチャンネル専用で、第三者に提供していません。
